Goal

Sumo with circles. Push every enemy unit out of the ring before your opponent does the same to you. Nothing slows down on its own, the ring keeps shrinking, and a well-timed shove is all it takes.

Source code of the referee and viewer: github.com/Waffle3z/CG-Knockout

  Rules

Two players each control 6 round units on a circular ring centered on (0, 0), with radius 5000. Every unit is a disc of radius 400, and all units have the same mass. Both players move at the same time.

Moving

Each turn, you give every one of your units a target point and a power between 0 and 100. The unit accelerates toward the target with that power. There is no friction: a unit keeps sliding until it thrusts the other way, plants its feet, or bumps into someone.

Units bounce off each other, and pushing is how you win. A unit whose center is outside the ring at the end of a turn is knocked out and removed from the game.

Stamina, DASH and PLANT

Every unit has stamina, between 0 and 100. It starts at 100 and recovers 6 at the end of every turn. Instead of a plain move, a unit may use one ability per turn:

  • DASH costs 40 stamina. That turn, the power is multiplied by 5 (up to 500).
  • PLANT costs 25 stamina. That turn, the unit digs in: its speed is reduced by up to 150. Planting stops a slide quickly and resists a single pusher, but two pushers or a DASH will move a planted unit.

A planted unit can still thrust, so planting while thrusting against your motion is the fastest way to brake. If a unit doesn't have enough stamina, the ability is ignored and the move is played as a plain move.

The ring shrinks

The ring keeps radius 5000 for the first 100 turns. From turn 101 on, it shrinks by 40 every turn, down to a minimum radius of 500. You receive the current radius every turn.

Victory Conditions
  • Every enemy unit has been knocked out, or
  • after 225 turns, you have more units left than your opponent.
Defeat Conditions
  • All of your units have been knocked out.
  • Your program does not answer in time, or prints something that is not one valid line per unit. This loses the game immediately, however many units you have left.
If both players lose their last unit on the same turn, or have as many units left after 225 turns, the game is a draw.

  Examples

A unit standing still at (3000, 0) with 100 stamina, nobody else nearby:

  • 0 0 100: it ends the turn at (2938, 0) with velocity (-100, 0). Next turn it keeps sliding at that speed even with power 0.
  • 0 0 100 DASH: it ends at (2688, 0) with velocity (-500, 0) and 66 stamina (100 − 40 + 6).

The same unit sliding outward with velocity (300, 0):

  • 0 0 0 (no thrust): it coasts to (3300, 0), still at 300.
  • 0 0 0 PLANT: it brakes to (3244, 0) with velocity (150, 0) and 81 stamina. Thrusting toward the center at the same time brakes harder.

  Expert Rules

The complete simulation of one turn is below, so you can reproduce the referee exactly. Positions and velocities are integers between turns; within a turn, use double-precision floating point. All units are processed in increasing id order.

for each unit W:
    p = clamp(power, 0, 100)
    if action is DASH and W.stamina >= 40:   W.stamina -= 40;  p = p * 5
    if action is PLANT and W.stamina >= 25:  W.stamina -= 25;  W.planted = true
    (dx, dy) = target - W.pos;  d = sqrt(dx*dx + dy*dy)
    W.acc = (dx / d * p, dy / d * p)               # (0, 0) if d == 0

repeat 4 times:                                    # 4 sub-steps of a quarter turn
    for each unit W:
        W.v += W.acc / 4
        W.pos += W.v / 4
    for each pair (A, B) with A.id < B.id, in order of (A.id, B.id):
        (dx, dy) = B.pos - A.pos;  d = sqrt(dx*dx + dy*dy)
        if d < 800:                                # the discs overlap
            n = (dx / d, dy / d)                    # (1, 0) if d == 0
            closing = dot(B.v - A.v, n)
            if closing < 0:                         # moving into each other: bounce
                j = -0.75 * closing                 # restitution 0.5, equal masses
                A.v -= j * n;  B.v += j * n
            push = (800 - d) / 2                    # separate them, half each
            A.pos -= push * n;  B.pos += push * n
    for each planted unit W:                     # grip: 150 per turn, 37.5 per sub-step
        s = sqrt(W.vx*W.vx + W.vy*W.vy)
        if s <= 37.5:  W.v = (0, 0)
        else:          f = (s - 37.5) / s;  W.v = (W.vx * f, W.vy * f)

for each unit W:
    W.pos = round(W.pos)           # to the nearest integer, halves away from zero
    W.v = truncate(W.v)            # toward zero
remove every unit with x*x + y*y > radius*radius
every remaining unit: stamina = min(100, stamina + 6)

Each pair is resolved once per sub-step, using the positions and velocities already updated by earlier pairs in that sub-step. To match the referee bit for bit, evaluate expressions in the order written, use sqrt (not hypot) and do not let the compiler fuse multiply-adds (for C++, compile with -ffp-contract=off). The radius used for the knockout test is the one you received this turn. Starting positions are random and point-symmetric: the opponent's units start at the mirror image (-x, -y) of yours.

  Game Input/Output

Initialization input
Line 1: unitsPerPlayer, the number of units each player starts with.
Input for one game turn
Line 1: two integers: turn (starting at 1) and radius, the ring radius this turn.
Next line: myCount, your units still in the ring.
Next myCount lines: six integers id x y vx vy stamina, in increasing id order. Velocities are in distance per turn.
Next line: oppCount, the opponent's units still in the ring.
Next oppCount lines: six integers id x y vx vy stamina, in increasing id order.
Output for one game turn
myCount lines: one per unit, in the order they were given: x y power, optionally followed by DASH or PLANT. Anything after that is shown as a message above the unit (its first 40 characters).
Examples: 0 0 100 · -1200 350 100 DASH · 2000 0 0 PLANT hold!
Constraints
unitsPerPlayer = 6
-100000 ≤ target x, y ≤ 100000
0 ≤ power ≤ 100
Response time for the first turn ≤ 1000 ms
Response time per turn ≤ 50 ms

Leagues

The full rules apply in every league. Each league below the top one has a boss to beat:

  • First league: every unit charges at the nearest enemy unit.
  • Second league: every unit rushes to the center and DASHes whenever it can. Joining the crowd in the middle is not enough; you have to push units out of it.

In the top league, the default opponent searches a few turns ahead and goes after your most exposed unit.
